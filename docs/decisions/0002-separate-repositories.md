# 0002. 학습 사이트와 실습 코드를 별도 저장소로 관리한다

## 결정

`claude-engineering-course`에는 사이트와 콘텐츠를, `globalpay-commerce-lab`에는 학습자가 다룰 실습 코드와 시뮬레이터를 둔다.

## 이유

- 학습자는 실습 저장소만 내려받아 코드 작업에 집중할 수 있다.
- 사이트 개발 이력과 실습 코드의 Git 이력을 분리할 수 있다.
- 콘텐츠와 실습 코드의 릴리스 주기를 독립적으로 관리할 수 있다.

## 제약

- 콘텐츠는 호환되는 실습 저장소 릴리스와 Git 태그를 명시해야 한다.
- 공개된 `start` 및 `reference` 태그를 변경하거나 재사용하지 않는다.
- 사이트 빌드 과정에서 실습 메타데이터 형식을 검증한다.
