# 0001. 사이트 안내와 로컬 실습을 결합한다

## 결정

학습 사이트는 개념과 과정을 안내하고, 학습자는 자신의 로컬 환경에서 Claude Code와 실습 저장소를 사용한다.

## 이유

- 실제 업무 환경과 유사하다.
- Claude Code 인증과 실행 환경을 사이트가 대신 운영할 필요가 없다.
- 브라우저 IDE, 컨테이너 격리, 비용 및 실행 보안이 MVP를 압도하지 않는다.
- 교육 콘텐츠와 Claude 활용 방식에 집중할 수 있다.

## 결과

학습자는 Java, Docker, Git, IntelliJ IDEA 또는 터미널 환경을 준비해야 한다. 사이트는 설치와 문제 해결 안내를 제공한다.
