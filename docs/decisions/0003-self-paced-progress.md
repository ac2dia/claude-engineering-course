# 0003. MVP는 계정 없는 개인 자율 학습으로 제공한다

## 결정

MVP에는 로그인, 서버 진도 저장과 관리자 기능을 포함하지 않는다. 진도, 힌트 상태, 메모와 회고는 브라우저에 저장한다.

## 이유

- 하루 1~2시간씩 진행하는 개인 학습이 우선 사용 사례다.
- 계정과 개인정보 운영 없이 핵심 학습 경험을 빠르게 검증할 수 있다.
- 서버 없이 정적 호스팅으로 운영할 수 있다.

## 보완

- 진도 데이터를 JSON으로 가져오고 내보낼 수 있게 한다.
- 콘텐츠 버전별로 진도를 분리한다.
- 민감 정보가 브라우저 저장소에 들어가지 않도록 안내한다.
