# 프로젝트 개요

## 문제 정의

Claude를 처음 접하는 개발자는 코드 생성 기능에 집중하기 쉽지만, 실무에서는 코드베이스 탐색, 요구사항 구체화, 가정 검증, 변경 범위 통제, 테스트 및 diff 검토가 더 중요하다. 이 과정은 Claude에게 코딩을 대신 시키는 법이 아니라 Claude와 함께 신뢰할 수 있는 소프트웨어를 만드는 법을 교육한다.

## 주요 학습자

- 서비스 회사에서 제품을 개발하고 운영하는 소프트웨어 엔지니어
- Java 또는 Kotlin과 Spring Boot를 주로 사용하는 엔지니어
- 일반적인 웹·백엔드 개발 경험은 있으나 Claude와 LLM 개발 도구 경험은 거의 없는 엔지니어
- AI 제품 창업이나 Claude API 기반 서비스 개발보다 기존 개발 업무의 생산성과 품질 향상이 목적인 엔지니어

## 학습 완료 후 역량

학습자는 다음을 할 수 있어야 한다.

1. Claude의 특성과 한계를 설명한다.
2. Claude 웹과 Claude Code의 역할을 구분한다.
3. 작업에 필요한 컨텍스트와 지시사항을 제공한다.
4. 기존 코드베이스를 조사하고 주장에 대한 코드 근거를 요구한다.
5. 요구사항을 완료 조건과 구현 계획으로 변환한다.
6. 기능 구현, 버그 분석, 테스트, 리팩터링에 Claude를 활용한다.
7. 생성된 변경 사항을 테스트와 diff로 검증한다.
8. 보안, 민감 정보, 권한 및 도구 실행 위험을 인식한다.
9. Claude의 제안을 수정하거나 거절한 근거를 설명한다.
10. 개인 업무에 적용할 반복 가능한 작업 절차를 작성한다.

## 교육 범위

### 핵심 범위

- Claude와 LLM의 기본 개념
- Claude Code의 기본 사용
- 컨텍스트, 프로젝트 지침, 권한과 도구 실행
- 코드베이스 탐색과 근거 확인
- 요구사항 구체화와 계획 검토
- 작은 단위의 구현과 검증
- 디버깅, 테스트, diff 리뷰 및 실패 복구
- 개인 개발 워크플로와 팀 규칙의 기초

### 보조 범위

- Claude 웹을 이용한 설계 논의와 기술 학습
- 로그와 문서 등 비코드 자료 분석
- MCP와 에이전트 개념의 개요

### MVP 제외 범위

- Claude API 기반 애플리케이션 개발
- AI 제품 기획, RAG, 챗봇 및 에이전트 서비스 구축
- 모델 학습과 파인튜닝
- 브라우저 내 IDE 또는 Claude 실행 환경
- 조직 계정, 관리자 대시보드 및 자동 코드 채점
- 결제 규제와 카드 네트워크에 대한 심화 교육

## 실습 프로젝트

가칭 `GlobalPay Commerce`는 주문과 글로벌 결제를 다루는 모듈형 모놀리스다. Java와 Kotlin, Spring Boot, Gradle, JUnit, PostgreSQL 및 Testcontainers를 기본 환경으로 한다.

주요 모듈은 다음과 같다.

```text
order
payment
refund
pricing
provider
reconciliation
customer
shared
```

외부 시스템은 Mock PSP와 Webhook 시뮬레이터로 제공한다. 타임아웃, 중복 Webhook, 지연 이벤트, 잘못된 이벤트 순서와 일시 장애를 재현할 수 있어야 한다.

## 성공 기준

MVP는 학습자가 다음 경험을 완료할 수 있으면 성공으로 본다.

- 8개 세션을 자신의 속도로 진행한다.
- Claude를 사용해 코드베이스를 조사하고 기능을 수정한다.
- 핵심 실습에서 로컬 테스트와 diff 검토를 수행한다.
- Claude의 가정 또는 제안을 한 번 이상 수정하거나 거절하고 그 근거를 기록한다.
- 마지막에 개인 Claude 개발 워크플로를 작성한다.
