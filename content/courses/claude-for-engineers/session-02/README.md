# Session 2 설계: 근거를 요구하며 코드 탐색하기

## 세션 목표

학습자는 Claude에게 코드를 수정시키기 전에 읽기 전용 조사를 요청하고, `POST /api/payments`에서 Mock PSP까지의 흐름을 파일 근거와 함께 설명합니다. Claude의 설명을 그대로 받아들이지 않고 직접 코드 위치를 대조해 사실, 해석, 가정을 분리합니다.

## 예상 시간

| 순서 | 페이지 | 시간 |
|---|---|---:|
| 1 | 조사 모드와 근거의 기준 | 10분 |
| 2 | 결제 요청 흐름 추적 | 25분 |
| 3 | Claude의 주장을 코드로 검증 | 15분 |
| 4 | 개념 확인과 회고 | 10분 |
| 합계 |  | 60분 |

## 실습 환경

- 저장소: `globalpay-commerce-lab`
- 저장소 버전: `v0.1.0`
- 시작 태그: `lab-02-start`
- 기술: JDK 21, Spring Boot 3.5, Java + Kotlin, H2
- 변경 허용: 없음. Session 2는 조사 전용이다.

## 완료 조건

- [ ] 읽기 전용 조사 요청을 작성했다.
- [ ] API 진입점에서 PSP 호출까지의 흐름을 파일 경로와 코드 위치로 설명했다.
- [ ] 주요 주문·결제 상태와 트랜잭션 경계를 찾았다.
- [ ] Claude가 제시한 근거를 직접 열어 대조했다.
- [ ] 확인된 사실, 해석, 확인 불가 항목을 분리했다.
- [ ] 코드 변경 없이 세션을 마쳤다.
