# 모호한 결제 장애 요청 개선하기

## Claude 학습 목표

- 모호한 업무 요청에서 확인되지 않은 정보를 발견합니다.
- 구현과 조사를 분리합니다.
- Claude에게 코드 근거와 불확실성 표시를 요구합니다.
- 처음부터 완벽한 해결책을 요구하지 않고 다음 판단에 필요한 정보를 얻습니다.

## 업무 티켓

```text
제목: 유럽 결제 실패 증가

어제부터 유럽 고객의 결제 실패가 증가했습니다.
PSP가 불안정한 것 같으니 재시도를 추가해 주세요.
```

## Domain Brief

이번 활동에서 알아야 할 내용:

- PSP는 외부 결제 처리 사업자입니다.
- 요청이 타임아웃되어도 PSP가 결제를 처리했을 수 있습니다.
- 동일 결제를 다시 요청하면 중복 승인 위험이 있을 수 있습니다.

이번 활동에서 다루지 않는 내용:

- 카드 네트워크의 상세 승인 절차
- 국가별 결제 규제
- 실제 PSP별 API 계약

## 1. 바로 구현을 요청하면 무엇이 부족할까요?

다음 요청을 Claude에게 보냈다고 가정합니다.

```text
결제 실패가 많아졌어. PSP 호출에 재시도를 추가해 줘.
```

코드를 수정하기 전에 확인해야 할 내용을 적어보세요.

<LearningNote id="session-01-missing-context" prompt="현재 요청에서 부족한 정보와 위험한 가정을 적어보세요." />

확인 후보:

- 실패의 정확한 정의와 오류 유형
- 문제가 시작된 시각과 영향 범위
- PSP 요청이 전송되기 전 실패인지, 전송 후 응답 유실인지
- 기존 재시도와 멱등성 처리 여부
- 결제 상태 조회 또는 Webhook 지원 여부
- 재현 가능한 로그, 요청 ID와 테스트
- 정상 동작과 완료 조건

## 2. 가상의 최초 응답을 검토합니다

다음은 교육을 위해 만든 가상 응답이며 실제 Claude 출력이나 공식 권장 답변이 아닙니다.

```text
PaymentProviderClient의 호출을 최대 3회 재시도하도록 수정하겠습니다.
외부 API의 일시적인 네트워크 오류는 지수 백오프로 재시도하는 것이 일반적입니다.
RetryTemplate을 추가하고 테스트도 작성하겠습니다.
```

문제가 되는 부분을 표시해 보세요.

- 현재 저장소의 실제 클래스와 흐름을 확인하지 않았습니다.
- 장애가 일시적인 네트워크 오류라고 가정했습니다.
- PSP가 이미 결제를 처리했을 가능성을 검토하지 않았습니다.
- 멱등성 계약과 기존 상태 모델을 확인하지 않았습니다.
- “일반적인 해결법”을 현재 시스템의 해결책으로 바로 연결했습니다.

## 3. 조사 중심의 첫 요청을 작성합니다

다음 네 요소를 포함해 요청을 다시 작성하세요.

1. 아직 코드를 수정하지 않는다는 경계
2. 조사할 흐름과 증거
3. 사실과 가정의 분리
4. 다음 의사결정에 필요한 결과물

## 참고 요청

먼저 자신의 요청을 작성한 뒤 비교하세요.

<details>
<summary>참고 요청 보기</summary>

```text
아직 코드를 수정하거나 해결책을 확정하지 마세요.

유럽 결제 실패 증가와 관련해 현재 저장소에서 다음 내용을 조사하세요.

1. 결제 요청의 진입점과 PSP 호출까지의 흐름
2. PSP 호출 전후에 저장되는 Payment 상태
3. 현재 재시도와 멱등성 처리 여부
4. 관련 테스트와 로그에서 확인 가능한 실패 유형

각 주장에는 파일 경로와 코드 위치를 근거로 제시하세요.
코드만으로 확인할 수 없는 내용은 `가정` 또는 `추가 정보 필요`로 분리하세요.

마지막에는 가능한 해결책을 구현하지 말고,
해결 방향을 결정하기 위해 추가로 필요한 운영 정보와 질문을 정리하세요.
```

</details>

참고 요청은 유일한 정답이 아닙니다. 자신의 요청이 더 짧거나 다른 형식이어도 조사 범위와 불확실성을 통제할 수 있다면 적절합니다.

## 자기 검토

- [ ] 구현 전에 조사를 요청했다.
- [ ] 확인할 코드 흐름을 구체화했다.
- [ ] 코드 근거를 요구했다.
- [ ] 사실과 가정을 분리하게 했다.
- [ ] 운영 정보가 없으면 모른다고 표현하게 했다.
- [ ] 재시도를 정답으로 미리 확정하지 않았다.
