# 결정과 diff를 검토하고 일곱 번째 원칙 세우기

## 전체 검증

```bash
./gradlew test
git status --short
git diff --stat lab-07-start
git diff lab-07-start
```

```text
lab-07-start 이후 전체 diff를 결정 기록과 대조해 리뷰하세요.
- 허용 전이 표의 각 셀에 대응하는 테스트
- entity와 Webhook 정책 사이의 중복 또는 방어 누락
- 종결 상태를 덮어쓸 수 있는 우회 경로
- IGNORED 이유가 저장되지 않는 경로
- 합의하지 않은 상태·이벤트·추상화

코드를 수정하지 말고 파일 경로와 테스트 근거를 제시하세요.
```

## 참고 구현과 비교

자신의 구현과 판단 기록을 마친 뒤 실행합니다.

```bash
git diff lab-07-reference -- src/main src/test
git show --stat lab-07-reference
```

참고 구현은 작은 `PaymentTransitionPolicy`와 정책 단위 테스트를 선택했습니다. 자신의 구조가 더 단순하거나 더 확장 가능하다면 그 대신 어떤 보장과 비용을 갖는지 설명하세요.
