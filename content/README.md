# 콘텐츠 작성 규칙

## 기본 원칙

- 레슨 제목과 목표는 결제 기능보다 Claude 역량을 먼저 표현한다.
- 공개된 사실, 개념적 설명, 실무 권장사항과 주의사항을 구분한다.
- Claude 및 Claude Code의 변경 가능한 기능은 공식 문서로 검증하고 검토 날짜를 기록한다.
- 공개되지 않은 제품 내부 구조를 사실처럼 추측하지 않는다.
- 결제 지식은 실습에 필요한 최소 범위만 `Domain Brief`로 제공한다.
- 완성 프롬프트를 먼저 제시하지 않고 학습자의 조사와 판단을 유도한다.

## Domain Brief 템플릿

```text

- 실습에 필요한 핵심 규칙

주의해야 할 오해
- 초보자가 하기 쉬운 잘못된 가정

이번 과정에서 다루지 않는 내용
- Claude 학습과 직접 관련 없는 도메인 심화 주제
```

## 검토 체크리스트

- [ ] Claude 역량이 주 학습 목표인가
- [ ] 다른 도메인에서도 재사용할 수 있는 역량인가
- [ ] 결제 지식이 부족해도 진행할 수 있는가
- [ ] 주장에 공식 출처 또는 코드 근거가 있는가
- [ ] 학습자가 Claude의 제안을 검증할 기회가 있는가
- [ ] 명확한 중단 및 재개 지점이 있는가
- [ ] 60~90분 안에 완료 가능한가
- [ ] 힌트가 답을 즉시 노출하지 않는가
- [ ] 테스트 통과 외의 리뷰와 회고가 있는가
